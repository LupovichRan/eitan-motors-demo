# איתן מוטורס — אתר הדגמה

דמו בעברית וב־RTL לאתר מכירת רכבי יד שנייה, מותאם למחשב ולנייד.

- קטלוג רכבים עם סינון, מיון, מועדפים ופרטי רכב.
- **מכוניתי** — עוזר חיפוש בכפתורי בחירה בלבד, לפי תקציב, שימוש, הנעה ושנתון. מבוסס כללים מקומיים, ללא שירות AI חיצוני.
- **ממשק מנהל** — הוספה ועריכת מלאי, תמונות, סטטוסים וייבוא/ייצוא גיבוי.
- התאמות נגישות ועמודי פרטיות, תנאי שימוש, אחסון מקומי והצהרת נגישות.

## צפייה

אתר ההדגמה: https://lupovichran.github.io/eitan-motors-demo/

ממשק מנהל: https://lupovichran.github.io/eitan-motors-demo/admin.html

## הרצה מקומית

אין צורך בהתקנת חבילות או בשלב בנייה. מתוך תיקיית הפרויקט:

```sh
python -m http.server 8080
```

פותחים `http://localhost:8080` בדפדפן.

## פרסום

להפעלה ראשונה: בהגדרות המאגר פותחים Pages, בוחרים Deploy from a branch, ואז main ו־/(root), ושומרים. לאחר מכן דחיפת עדכונים לענף main תעדכן את האתר.

## גבולות ההדגמה

נתוני הרכבים, המחירים ותמונות האווירה הם להמחשה ואינם הצעות מכירה. אין שליחת לידים, סליקה או חיבור WhatsApp פעיל.

ממשק המנהל אינו מוגן בהתחברות נפרדת: השינויים נשמרים בדפדפן המקומי ומשפיעים רק על הקטלוג באותו פרופיל דפדפן. משתמשים אחרים רואים מלאי הדגמה משלהם. אין להזין מידע אישי או עסקי רגיש. לאתר חי נדרשים התחברות, הרשאות בצד שרת, מסד נתונים ואחסון קבצים.

השיחה עם מכוניתי נמצאת בזיכרון העמוד בלבד. העדפות הנגישות ומלאי ששונה נשמרים ב־localStorage. תמונות וגופנים נטענים משירותים חיצוניים.

בדיקות דפדפן וסריקת נגישות אוטומטית בוצעו במהלך הפיתוח; אין בכך אישור עמידה מלאה בתקן או חוות דעת משפטית. לפני שימוש עסקי יש להשלים בדיקות, פרטי עסק, דרכי קשר ומסמכי מדיניות התואמים לפעילות בפועל.

תמונות האווירה: Unsplash. גופנים: Google Fonts. שימוש נוסף בנכסי צד שלישי כפוף לרישיונות שלהם.

## הקשחת אבטחה

הגרסה כוללת CSP במסמכי HTML, הגבלת מקורות תמונה, אימות קבצים ונתוני מלאי. GitHub Pages אינו מחיל את קובץ `_headers`; כותרות הגנה נוספות נדרשות משכבת אירוח מתאימה. דוח הבדיקה של גרסת Sites נמצא בקובץ SECURITY-REVIEW.md ומתאר גם את ההבדל הזה.

## בדיקות נגישות

נבדקים כל 40 שילובי הגדרות הנגישות שהדמו מציע, כולל טקסט עד 200%, חלונות ניהול ומכוניתי ותצוגת נייד. פירוט ותוצאות ב־[ACCESSIBILITY-VALIDATION.md](ACCESSIBILITY-VALIDATION.md). חבילות `package.json` הן לצורכי בדיקות פיתוח בלבד; האתר ממשיך לפעול כקבצים סטטיים ללא שלב בנייה.
